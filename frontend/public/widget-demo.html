🚀 How to Embed

Add this single line of code to your website to embed the ProfileGPT widget:

<script src="http://localhost:3000/widget.js" data-tenant="demo-tenant"></script>

For Production Deployment:

<script src="https://yourdomain.com/widget.js" data-tenant="your-tenant-id"></script>

That's it! The chat widget will appear in the bottom-right corner of your site.
